## 해결하는 이슈

- **P1-1 잊은 비밀번호에서 빠져나갈 길이 없음.** 로그인에 "비밀번호를 잊었어요"(`.onb-back` 계열 텍스트 버튼, 44px)와
  "처음이에요 · 시작하기"(`.onb-login` 계열)를 넣었어요.
  - 경로는 team-lead가 정했어요: 앱에서 인증해 둔 전화번호로 문자 코드를 받아 확인하고, 새 비밀번호를 만들어요.
  - `A-reset` / `B-reset`이 그 첫 시트예요: 제목 "비밀번호 다시 만들기", 아이디 칸, "문자 코드 받기".
  - 시트 머리 왼쪽 원형 버튼으로 로그인에 돌아가요. 2단계의 "이전 단계"와 같은 자리예요.
  - 전화번호를 인증하지 않은 경우도 한 줄로 말해요: "전화번호를 인증하지 않았다면 비밀번호를 다시 만들 수 없어요. 새 아이디로
    시작하면 새 모시를 만나요." 그 아래 "새 아이디로 · 시작하기"가 그 경우의 유일한 길이에요.
  - 코드 입력과 새 비밀번호 단계는 같은 시트 안의 content swap이에요. 그리지 않았어요.
  - **서버 작업 필요:** 전화번호 인증 기반 재설정 엔드포인트가 필요해요. 문자 코드 발송·확인 후 비밀번호를 바꾸고, 인증한
    번호가 없으면 그 사실을 응답해요. 사용자가 onboarding 시안을 고르면 일정에 넣어 주세요.
- **P2-1 만나는 캐릭터와 남는 캐릭터가 다름.** 첫 화면, 가입 시트, 채팅이 같은 spec을 써요. 새 색은 UI에 들어오지 않고 캐릭터
  안에만 있어요(The Agent Owns Its Colour).
- **P2-2 두 단계가 한 틀을 쓰지 않음.** 시트 높이를 맞추고 뒤로를 머리 왼쪽으로 옮겼어요. `Sheet`에 `leading` 슬롯이 필요해요.
- **P3-1 개발자 말투의 아이디 규칙.** 힌트 문구만 바꿨어요. 검증 규칙은 같아요.
- **P1-2 (detector B) CTA 대비 3.6:1.** `--accent-fill`로 해결돼요. 이제 앱 토큰에도 들어가 있어요.
- **형식 밖의 메모(fixes에는 넣지 않음).** 2단계 자동 포커스를 빼서 한 화면의 파란 요소를 줄였어요. B의 부제 변경은
  설득(Persuade) 쪽 제안이에요.

## A와 B

- **A**는 화면 구조를 바꾸지 않아요. 코드 변경은 다섯 군데예요: `AgentBlobLazy`에 spec 넘기기, 가입 직후 avatar PATCH,
  `.onb-form` 높이, Sheet `leading`, 로그인의 두 텍스트 버튼.
  - 이름 칸 앞의 얼굴은 TextField에 `leading` 슬롯을 하나 더하는 작업이에요.
  - 이름 짓는 순간 캐릭터는 여전히 어두운 스크림 아래에 있어요.
- **B**는 감정의 정점인 이름 짓기를 캐릭터 앞에서 하게 해요. 스크림이 없고, 캐릭터는 시트 위에서 밝은 그대로 있고,
  짓는 이름이 그 아래에 바로 보여요. 부제는 다른 비서 앱이 할 수 없는 일을 말해요(Persuade). 비용은 세 가지예요.
  - 시트가 열릴 때 캐릭터가 히어로 자리에서 시트 위로 옮겨 가는 공유 요소 morph를 하나 만들어야 해요.
  - 스크림 없는 시트도 모달이에요. 포커스 트랩은 그대로 두고, 뒤쪽은 inert로 처리해요.
  - 부제는 사실 확인이 필요해요. PRODUCT.md의 기능 목록(전화 대행, 카카오톡)과 맞아요.
- **추천: B.** critique가 꼽은 가장 큰 기회가 "만나는 캐릭터가 남는 캐릭터이고, 이름 짓는 단계가 그 캐릭터를 보게 하는
  것"이에요. B는 그걸 한 화면 안에서 보여 줘요. 부제 변경이 부담되면 B의 시트 처리만 가져가고 부제는 A로 둬도 돼요.

## 모션 (MOTION-SPEC, 바꾸지 않음)

- 시작하기 → 시트가 버튼에서 morph로 나와요(§6.1). 단계 사이는 content swap이에요(exit 120 → enter +60, §3).
- 주 버튼은 서버 확인 뒤에만 loader → check예요(§3). 성공하면 시트가 상단 바 아바타로 줄어들어요(§6.1).
- 캐릭터 호흡은 3.2 s, ≤2 %예요. 화면 밖이거나 입력 없이 10 s가 지나면 멈추고, reduced motion에서는 정지해요(§8.11).
- 시트를 닫을 때 뒤 화면은 첫 프레임부터 완전히 보여요(§8.2 returns never re-enter).
- **B가 더하는 것.** 시트가 열릴 때 캐릭터가 히어로에서 시트 위 무대로 옮겨 가요(`layoutId` 공유 요소, `morph`, 208 → 168px).
  제목과 부제는 `fade`로 빠져요. 닫히면 반대로 돌아와요. 무대 위 이름은 입력과 같은 프레임에 바뀌어요(애니메이션 없음).
  실제 상태 변화에 묶인 움직임이라 "nothing moves without meaning"에 맞아요.
