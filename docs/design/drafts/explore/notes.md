## 해결하는 이슈

- **P1 만든 숫자(CP-7).** `count`를 화면에서 지웠어요. 서버 쪽 수정은 critique 그대로예요: seed `count: 0`, 정렬은 `sort`,
  실제 사용자 수가 기준을 넘을 때만 "N명이 맡겼어요". 그 전에는 아무 숫자도 보이지 않아요.
- **P1 전화 체험이 약속과 다름.** 시트에 빠진 준비물 "내 전화번호"를 보여 줘요. "따로 연결할 건 없어요"라는 거짓을 없앴어요.
  - `needsFor`에 `usePhone()` 미인증 조건을 더하면 돼요.
  - 인증 전에는 주 버튼이 "인증하고 받아 보기" 하나예요(design-director 리뷰). 누르면 `presentPhone`이 열리고, 인증이
    끝나면 같은 버튼이 이어서 맡기기를 해요. 행에는 버튼을 따로 두지 않아요. 누르면 무슨 일이 일어나는지 모호하지 않게 하려는
    거예요. 인증된 사람에게는 행이 보이지 않고, 버튼도 원래 문구 "전화 받아 보기"예요.
  - 스레드 첫 메시지가 약속과 어긋나는 문제는 서버 쪽 수정이에요(phone-delegation P1). 시안에는 그리지 않았어요.
- **P2 장식 색 30가지(IT-11 · IT-12 · IT-13 · SH-2).** 색 판과 파스텔 원, `HUE` 맵을 지웠어요. 화면의 색은 탭 바 선택과
  시트의 CTA 하나뿐이에요.
- **P2 상자 다섯 개짜리 시트(NC-6).** 시트는 머리말 하나, 번호 목록 하나, 사실 한 줄, 안내 한 줄, 강조색 하나로 끝나요.
- **P2 23행의 벽.** 제안을 맨 위로 올리고 설명을 두 줄로 줄였어요. A는 여섯째 카테고리가 보이게 했고,
  B는 추천을 5행으로 줄였어요.
- **RH-3 · RH-1 · GL-2.** 둘러보기의 "초대" 캡슐을 뺐어요. 초대는 친구 화면에 남아요.
  - 탭 루트에서 에이전트 이름은 채팅에만 보여요(_kit/README "Shared top-bar rule"). 그래서 가운데 "깽이" 캡슐도 뺐어요.
  - 유리는 메뉴 원과 탭 바, 둘이에요. 큰 제목이 접히면 "둘러보기"가 캡슐 없이 맨 글자로 나와요.
- **minor.** `.cat-label`의 `opacity .78` 대신 `--label-2`를 쓰고, `.tpl-list` 그림자를 빼서 Flat Paper로 맞췄어요.

## A와 B

- **A**는 화면의 모양과 행동을 그대로 두고 찌꺼기만 걷어 내요. 코드 변경은 CSS 몇 줄과 섹션 순서, `showCount = false`예요.
  - 22 px 글리프는 줄을 훑을 때 눈이 걸릴 자리로 남겼어요(IT-15와 같은 처리).
  - 카카오톡 · 슬랙 행은 브랜드 마크 대신 `chat` 글리프를 써요. 제목에 이미 이름이 있어요.
  - 추천은 여전히 "전부"라서, 제안 아래에 22행이 이어져요.
- **B**는 critique의 선택 질문("추천은 전부인가, 나를 위한 것인가")에 "나를 위한 것"이라고 답해요.
  - 추천 = 깽이의 제안 + `category === "recommend"` 두 개예요. 전체 목록은 새 카테고리 "전체"와 마지막 행에 있어요.
  - 카테고리는 고르는 말이라 글자예요. 인벤토리 IT-12의 권고("Text segmented rail")를 따랐어요.
  - 시트는 Casey(한 손, 엄지) 기준으로, 빠진 준비물과 비용을 CTA 바로 위에 모아요.
  - 비용이 있어요. 카테고리가 하나 늘고 추천의 뜻이 바뀌어요. "전체 보기" 행은 rail의 "전체"를 고르는 것과 같아서,
    드롭렛이 그쪽으로 이동해요.
- **추천: B.** "Wall of Options"를 실제로 줄이는 건 B뿐이에요. 첫 화면이 "나에게 고른 일"로 시작하는 것도 B예요.
  - 추천의 뜻을 바꾸는 게 부담되면 B의 글자 줄, 행, 시트만 가져가요. 추천의 내용은 A처럼 "제안 + 전부"로 두면 돼요.

## 모션 (MOTION-SPEC, 바꾸지 않음)

- 큰 제목이 스크롤되면 빈 가운데에 "둘러보기"가 맨 글자로 나와요(§6.4 scroll edge). `A-end`, `B-end` 캡처에 보여요.
- 카테고리 선택은 무채색 드롭렛이 `lead`/`trail` 두 모서리로 늘었다 모이는 방식이에요(§6.4, §3).
  - B의 글자 줄도 같은 `useTwoEdge`를 써요. 바뀌는 건 드롭렛의 높이 40 px와 폭(글자 폭)뿐이에요.
  - 라벨 굵기는 착지할 때 `snap`으로 바뀌어요.
- 카테고리를 바꾸면 목록이 방향 있는 content swap으로 바뀌어요(exit 120 → enter +60, §3).
- 행 → 위임 시트는 shared-element morph예요(§8.9). 맡기기는 서버 확인 뒤 loader → check, 그다음 시트가 컴포저로 줄어들어요.
- 시트를 닫을 때 목록은 첫 프레임부터 완전히 보여요(§8.2).
