## 두 시안이 함께 고친 것

- **티켓을 색 대신 말로 (P1-1, CL-1; HEAD에서 이미 고쳐짐).** 파랑 `hsl(214…)`, 보라 `hsl(286…)` 티켓 두 개를 '기본 3장 · 프리미엄 0장' 한 줄로 바꿨어요(`--label-2`, tabular). 색만으로 구분하던 WCAG 1.4.1 문제와 One Voice Rule 위반이 같이 풀려요. 시트에서도 행 아이콘을 뺐고, 선택된 라디오는 `--accent` 원에 흰 체크예요(선택 상태라 accent를 써도 돼요).
- **종이는 평평하게, 반경은 하나로 (P2-2, SH-1, RD-1; 그림자, 다크 헤어라인, 반경 토큰은 HEAD에서 이미 고쳐짐).** 그림자를 모두 빼고 모든 상자를 `--r-group`(20)으로 맞췄어요. 섹션 간격은 14px에서 24px로 바꿨어요. light는 명도 차이로만 구분하고, 다크와 대비 높임에서는 앱(95c51d3 Flat Paper)과 같이 모든 종이에 안쪽 헤어라인 한 줄(`inset 0 0 0 1px var(--separator)`)이 있어요. 카드에만 선이 있고 목록 묶음에는 없던 문제(critique Engine 항목)가 없어져요. 종이 안의 종이는 선을 넣지 않아요.
- **보호 카드는 행으로 (P2-2, IT-17, CP-5; 안심 문구는 HEAD에서 이미 빠짐).** "개인 정보를 안전하게 보호하고 있어요" 배너 카드는 '개인 정보 보호 / 어떻게 암호화하고 보관하는지 알려 드려요' 행이 됐어요. 같은 시트를 열어요. 안심 문구는 개인 정보 시트 한 곳에만 남아요.
- **빈 상태는 한 번만 (RH-4).** '기록 없음' 옆에 '아직 사용한 기록이 없어요'를 또 쓰던 중복을 없앴어요.
- **진짜 h2 (P2-5, detector `skipped-heading`; HEAD에서 이미 고쳐짐).** 섹션 제목이 모두 `h2`예요. '내 계정' 묶음에도 보이는 제목이 생겼고, 그래서 계정 행 부제의 '내 계정 ·'은 뺐어요.
- **연결 카드의 "+" 타일 제거.** 카드나 행 전체가 버튼이라 타일이 하는 일이 없었어요. 연결된 서비스가 생기면 제3자 로고 플레이트(K, DESIGN이 허용)는 그대로 보여요.
- **페르소나는 첫 문장만.** "필요한 걸…"처럼 구 중간에서 잘리지 않아요. 접근성 이름도 페르소나 106자 전체가 아니라 '깽이 설정'이에요(critique Persona: Sam).
- **티켓 시트.** 오목한 '오늘 사용한 한도' 패널을 없앴어요(카드 안 카드 제거). 사용량이 0%이면 막대도 보이지 않아요. 바로 뒤 화면과 같은 줄이고, 버튼 위 안내 '지금은 초기화할 사용량이 없어요'가 같은 말을 해요. 사용량이 있을 때만 시트 맨 위에 '오늘 사용한 한도'와 막대가 나와요. 남은 티켓이 없는 '프리미엄 티켓'은 비활성이에요. 이름과 라디오는 흐리게, 이유('남은 티켓이 없어요')는 `--label-2` 그대로 읽히게 했어요. 체크 아이콘이 붙어 성공처럼 보이던 막힘 안내는 아이콘 없이 비활성 버튼 바로 위로 옮겼어요. 비활성 버튼은 파란 기가 없는 `--fill` + `--label-3`라, 파랑은 늘 "누르면 뭔가 일어나요"라는 뜻이에요.
- **값은 같은 말로.** 비어 있는 연결, 로그인, 결제 수단은 모두 오른쪽 값 '없음'으로 맞췄어요(이전 '0개'). B의 '연결된 앱 및 서비스' 행에서는 두 줄 부제를 뺐어요. 같은 안심 문구가 연결 화면에도 있어서예요(CP-5). A는 지금 카드 구성을 유지해서 그 문장이 카드 안에 남아요.
- **'결제 수단'.** 행 이름에서 '연결된'을 뺐어요. 이 버전에서는 연결할 수 없어서, 들어가는 화면의 큰 제목도 '결제 수단'이에요(payment critique Minor, `../payment/`).
- **채운 버튼 파랑 (GT-4; HEAD에서 이미 고쳐짐).** 앱 토큰 `--accent-fill`(#0071E3, 흰 글자 4.7:1)을 그대로 써요. 토큰이 95c51d3에 들어와서 fallback은 지웠어요.

## A: 조용한 정리 (보수적)

지금 배치와 상자 구성(에이전트 카드, 한도 카드, 7일 카드, 계정, 연결 카드, 깽이, 앱 사용)을 그대로 두고 위 항목만 고쳤어요.
- 행의 아이콘은 판 없이 20px 글리프로 글줄 안에 둬요(`--label-2`, 24px 열). critique 권고대로 행이 15개인 허브라서 훑어보기용 글리프는 남겼어요. 구분선은 글자 시작점(52px)에서 시작해요.
- 상단 가운데는 쉬는 동안 비어 있어요. kit 상단 바 규칙에서 탭 루트 가운데에 에이전트가 나오는 건 채팅뿐이고, 바로 아래 에이전트 카드가 깽이예요. 큰 제목이 접히면 '나의 모시'가 글자로 들어와요(RH-1).
- 서버 SDUI(`ui.profile.sections`) 변경이 필요 없어요. 화면 팀이 CSS와 문구만으로 낼 수 있어요.

## B: 하나의 목록 (대담하게)

critique의 "biggest opportunity"("one list vocabulary across the tab")와 질문 1("hub as one inset-grouped list")을 그대로 밀어붙인 안이에요.
- 탭의 모든 블록이 'h2 제목 → 묶음 → 설명' 한 문법이에요. 따로 놀던 카드 머리글(20px, 17px 두 가지)이 없어요.
- 한도는 '사용량' 묶음의 첫 행이에요: 제목과 0%, 막대, 초기화 시각이 들어가고 다음 행이 티켓이에요. 비어 있는 7일 기록은 묶음 아래 설명 한 줄이 되고, 기록이 생기면 그 자리에 막대 차트 행이 들어와요(§3 Chart 그대로).
- 아이콘 열을 없애는 대신 묶음을 의미별로 나눴어요: 내 계정 / 깽이(연결된 앱, 예약된 일, 친구, 정보 공개 범위) / 개인 정보와 보안(저장된 로그인, 결제 수단, 접근 기록, 개인 정보 보호) / 앱 사용. 7행이던 묶음이 4행 이하가 돼요(critique Cognitive Load의 chunking 실패).
- 가운데 이름표는 쉬는 동안 비워 둬요. 바로 아래 첫 행이 깽이예요. 큰 제목이 접히면 '나의 모시'가 content swap으로 들어와요. 유리 모양은 메뉴 원과 탭 바 둘이에요(RH-1, GL-2).
- 행 재배치는 서버 SDUI 섹션 순서와 제목을 바꿔야 해요(`apps/server` profile sections). 문법(카드 → 묶음)만 먼저 내고 재배치는 나중에 해도 돼요.
