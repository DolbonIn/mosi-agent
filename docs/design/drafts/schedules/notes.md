## 두 시안이 함께 고친 것

- **만드는 길은 하나 (P1-1; HEAD는 반대 방향, 아래 비교 참고).** 위쪽 '+' 유리 원을 없앴어요(`useTopBarRight`). 이것까지 4개였던 유리 모양이 뒤로 원과 탭 바 2개가 돼요. 엄지로 닿는 아래쪽 버튼만 남았어요. 힌트는 '모시' 대신 에이전트 이름을 써요(`${josa(agentName, "이가")}`). 띄어쓰기는 "깨워 줘"로 맞췄어요(`NEW_PROMPT`도 같이 바꿔요).
- **추측한 아이콘 타일 제거 (P2-1, IT-6, CP-8; 대화 카드 타일과 sparkles는 HEAD에서 이미 고쳐짐).** 제목을 보고 sun, checkmark, `sparkles`를 고르던 `iconFor`와 타일을 지웠어요. 행은 16px 여백에서 제목으로 시작하고 구분선도 16px에서 시작해요. 시트의 사실 행도, 대화 카드의 시계 타일도 지웠어요. '아직 없어요' 옆에 체크가 붙던 거짓 표시가 사라져요.
- **시간은 한 번 (P2-2).** '다음 오늘 오전 7:30'이 없어지고, 바뀌는 부분은 '다음은 오늘'(`whenKo`의 날짜 부분)뿐이에요. 꺼지면 '꺼져 있어요'예요. 시트의 다음 실행도 '꺼져 있어요'라 행과 시트가 같은 말을 해요(critique Minor).
- **시트 (P2-3).**
  - 오목한 패널과 타일을 빼고, 시트 위에 라벨과 값 행을 hairline으로 나눴어요.
  - 맡긴 일은 입력창 모양 상자가 아니라 따옴표 친 본문이에요. 눌러도 아무 일 없는 가짜 입력창이 없어져요.
  - '예약 지우기'는 보관함처럼 작은 가운데 캡슐이에요(`--fill` 위 `--danger` 글자). 시트에서 가장 큰 것이 지우기이던 문제가 풀려요. 안내 문장은 그 아래 그대로 있어요. 빨간 바탕 위 글자 대비는 HEAD에서 이미 `--danger-on-fill`로 고쳐졌어요. 시안이 바꾸는 건 크기와 무게예요.
- **대화 카드 (P2-4a; 클래스 충돌은 HEAD에서 이미 고쳐짐).** 타일 없이 '제목 / 규칙 + 스위치'만 남겼어요. 클래스 충돌(`.sched-icon`, `.sched-title`)은 타일이 사라지면 같이 없어져요. 카드 클래스는 `ccard-sched__*`로 이름공간을 따로 써요.
- **문자열 (P2-4b, c, 화면 밖).** 서버 이벤트 문구의 이모지(`⏰`, `☀️`)와 `을(를)`은 시안에 그리지 않았지만 같이 고쳐야 해요. 고친 결과는 `${s.title} · ${s.human}`, `오늘의 브리핑`, `${eulReul(s.title)}`예요.
- **진짜 h2 (P2-5; HEAD에서 이미 고쳐짐).** 섹션 제목은 `h2`이고, 시트 안 '깽이에게 맡긴 일'은 시트 제목(h2) 아래라 `h3`예요(detector `skipped-heading` 2건).

## HEAD(b3c2629)에서 이미 고쳐진 것

현재 캡처(41, 42, 16)는 b3c2629에서 찍었어요. 캡처와 코드를 같이 보고 나눴어요.

**고쳐짐 (`fixes`에서 뺐어요)**
- 만드는 버튼 셋(RH-2; ace3eb7): 아래 '새 예약 만들기' 버튼이 빠지고, 위쪽 '+'와 힌트가 남았어요. slop-inventory 권고 그대로예요. 시안은 반대로 '+'를 빼요(아래 P1-1과 'A와 B 비교' 아래 문단).
- 브리핑의 sparkles(CP-8; ace3eb7): 문서 글리프가 됐어요.
- 대화 카드의 시계 타일(IT-6; b3c2629): 타일이 빠지고 메타 줄 안의 14px 시계가 됐어요. 그래서 `chat` 상태에서는 P2-1도 뺐어요. 그 상태에서 P2-1이 가리키던 건 이 타일뿐이에요.
- 제목(P2-5; ace3eb7): 시트 안 '깽이에게 맡긴 일'이 h3예요.

**반대 방향이거나 일부만 고쳐짐 (`fixes`에 남겼어요)**
- 만드는 길(P1-1; ace3eb7): 길이 하나가 됐고, 힌트가 에이전트 이름을 쓰고, 예시 문장이 '깨워 줘'로 바뀌었어요. 남은 '+'는 누르면 대화창에 남이 쓴 모닝콜 문장을 채우기만 하고 보내지 않는데, '+'는 그 동작을 말해 주지 않아요. 시안은 '+'를 빼고 이름이 동작을 말하는 아래 캡슐(A)이나 예시 문장(B)을 남겨요.
- 유리 모양(GL-2): '+'가 남아서 뒤로, 이름 캡슐, '+', 탭 바 넷이에요. 시안은 둘이에요.
- 아이콘 타일(P2-1): sparkles와 대화 카드 타일은 빠졌어요. 행의 타일과 시트 사실 행의 타일(체크가 붙은 '아직 없어요' 포함)은 남아 있어요.
- 행의 시간(P2-2): '다음 오늘'은 '다음은 오늘'이 됐어요. 세 줄 행과 두 번 나오는 시간은 남아 있어요.
- 대화 쪽(P2-4): 클래스 충돌은 풀렸어요(목록은 `sched-row__*`로 이름을 바꿈, ace3eb7; 카드의 `.sched-icon` 삭제, b3c2629). 서버 이벤트 문구의 `⏰`, `☀️`, `'을(를)'`은 남아 있어요(`apps/server/src/schedules.ts`).

**그대로예요 (`fixes`에 남겼어요)**
- 시트(P2-3): 오목한 사실 패널, 입력창처럼 보이는 맡긴 일 상자, 시트에서 가장 큰 빨간 '예약 지우기'
- critique 질문 1: 시트에 바꾸는 길이 없어요('결과가 오는 대화 보기'만 있어요).

## A: 두 줄 행 (보수적)

- critique가 말한 그대로예요. 행은 제목(17/600)과 footnote `--label-2` 한 줄('매일 오전 7:30 · 다음은 오늘')이에요.
- 목록 아래에 '깽이에게 예약 부탁하기' 중립 캡슐 하나와 힌트 한 줄을 둬요. 보관함 빈 상태 CTA와 같은 말투예요. 누르면 지금처럼 대화창에 "매일 7시 30분에 깨워 줘"가 채워지지만 보내지는 않아요. 이름이 그 동작을 말해 줘요.
- **시트에서 바꾸는 방법을 말해요 (critique 질문 1, 지수).** '깽이에게 바꿔 달라고 하기' 중립 버튼이 맡긴 일 아래에 있어요. 지금은 시간을 바꾸려면 지우고 다시 부탁하는 수밖에 없는데, 대화로 바꾸는 길을 이름으로 알려 줘요. 누르면 대화창에 "모닝콜 바꿔 줘"가 채워지고, 보내지는 않아요. 처음엔 B에만 있던 버튼인데, 추천안이 viewer에서 그대로 보이도록 A에도 넣었어요.
- 대화 카드는 '아침 브리핑 / 매일 오전 7:00' + 스위치예요.

## B: 알람처럼 (대담하게)

- **시간이 행의 이름이에요.** iOS 알람처럼 22px tabular 시각이 먼저 오고, 아래 줄은 '모닝콜 · 매일 · 다음은 오늘'이에요. 시간 순으로 훑기 쉽고, 행마다 큰 글자는 하나뿐이에요.
- **만드는 길은 예시 문장이에요.** '깽이에게 부탁하기' 묶음에 빈 상태의 예시 문장 셋이 행으로 있어요(빈 대화 시안 A의 문장 행 패턴). 누르면 대화창에 채워지기만 하고, footer가 "시간을 고친 다음 보내면" 된다고 말해요. 남이 쓴 모닝콜 문장 하나만 채워 주던 문제(critique Jordan)가 풀려요.
- 시트는 A와 같아요. '깽이에게 바꿔 달라고 하기'도 있어요.
- 대화 카드도 같은 문법이에요: '오전 7:00' / '아침 브리핑 · 매일 · 다음은 내일' + 스위치.

**'+'와 아래쪽 만드는 길: HEAD와 방향이 달라요.** HEAD(b3c2629)는 slop-inventory RH-2 권고대로 위쪽 '+'와 힌트를 남기고 아래 버튼을 뺐어요. 두 시안은 반대로 '+'를 빼고 아래쪽(A는 캡슐, B는 예시 문장)을 남겼어요. 이유는 GL-2(유리 모양 4개 → 2개)와 엄지가 닿는 위치예요. 둘 다 DESIGN 안에서 성립하는 선택이라 고를 수 있어요. 차이가 하나 더 있어요. HEAD의 '+'는 누르면 대화창에 "매일 7시 30분에 깨워 줘"를 채우기만 하고 보내지 않는데, '+' 글리프는 그 동작을 말해 주지 않아요(읽어 주는 이름은 '새 예약 만들기'예요). 시안의 '깽이에게 예약 부탁하기'는 이름이 대화로 간다는 걸 말해 줘요.

**추천: A.** (B에서 나온 시트 버튼 하나를 A에도 넣었어요.)
- 예약은 알람만이 아니에요. 출석체크와 브리핑은 이름으로 기억해요. 같은 시각에 예약이 둘이면 B의 행은 이름 줄을 읽어야 구분돼요.
- B의 예시 문장 묶음은 예약이 이미 있는 화면에 상자를 하나 더 얹어요.
- '깽이에게 바꿔 달라고 하기'는 critique가 짚은 빈틈(바꿀 방법이 없음)을 버튼 하나로 메워요. 처음엔 B에만 있었는데, 사용자가 viewer에서 추천안을 그대로 보도록 A의 시트에도 넣었어요. 다른 것은 바뀌지 않아요.

## 유지하는 모션 (MOTION-SPEC)

- §3 Toggle: knob 두 모서리가 lead/trail로 움직이고, 트랙은 `snap`으로 채워지고, 누르고 있으면 렌즈가 돼요. 시안의 정지 화면에는 knob 이동과 트랙 색만 넣었어요.
- §3 Content swap: '다음은 오늘'과 '꺼져 있어요'가 바뀔 때 그 부분만 바뀌어요(`ContentSwap`, 120ms exit → +60ms enter). 행 글자색은 `--label-2`로 같이 바뀌어요.
- §3 Sheet: 행에서 morph로 펼쳐지고, 열려 있는 동안 원래 행은 비어 있어요(현재 42와 같고, 시트 캡처에도 그렇게 그렸어요). 닫힐 때 행은 첫 프레임부터 보여요(§8.2, 재등장 없음).
- §8.6 두 번 누르기: '예약 지우기' → '한 번 더 누르면 지워요'. 서버가 확인한 뒤에만 loader가 check로 바뀌고 시트가 닫혀요(§3 Loader → check).
- §8.13: 켜거나 끄지 못하면 토글이 되돌아가고 섬 배너가 한 번 말해요('켜지 못했어요' / '끄지 못했어요').
- B: 예시 문장을 누르면 press 틴트가 보이고 채팅으로 넘어가요. 컴포저는 채워진 채로 시작해요.

## 검사

- **impeccable detector** (엔진 0.1.18 캐시 바이너리, `detect --cdp`, Chrome light 390×844): A, B 모두 목록과 대화 카드는 0건이에요. AI-tell 0, `skipped-heading` 0, `low-contrast` 0이에요. 현재 앱은 `skipped-heading` 2, 대화 화면 `low-contrast` 4였어요. 시트 상태는 `text-occlusion`만 A 5, B 5예요. 모달 시트 밑에 깔린 페이지라 정지 화면에서 생기는 오탐이에요.
- 유리 모양: 목록은 2개(뒤로, 탭 바)예요. 대화는 3개(메뉴, 컴포저, 탭 바)이고, 가운데 이름은 kit 규칙대로 캡슐 없는 글자예요.
- 대화 속 카드 상태는 **카드만** 이 시안의 범위예요. 주변 스레드(말풍선)는 지금 앱 스타일 그대로예요(값은 chat 시안 A에서 가져왔어요). chat 시안이 추천하는 B(말풍선 없이 글자)와는 모양이 달라요. 카드 자체는 어느 스레드 스타일 위에서도 같아요.

## 이 시안에서 다루지 않은 것

- 빈 상태(예약 0개)는 그리지 않았어요. critique Minor에 따르면 예시 칩이 문장처럼 줄바꿈되는 문제가 있어요. B의 문장 행이 그 답이 될 수 있어요.
- '지금 한 번 실행하기'(critique 질문 3)는 넣지 않았어요. 모닝콜은 전화를 거는 일이라 시험 실행에도 확인이 필요해서, 제품 판단이 먼저예요.
